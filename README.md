# Proxmox Homelab

This repository documents my first homelab project, which I created to gain hands on experience with system administration, virtualization, networking, Windows Server, Active Directory, cloud technologies, and other core enterprise IT concepts.

I wanted to build this lab because I am interested in system administration and infrastructure focused IT work, but I also wanted experience beyond what I learn in the classroom. My goal is to create an environment where I can practice configuring systems, managing users and devices, troubleshooting problems, and learning how common business IT services work together.

Proxmox VE serves as the main virtualization platform for the lab and will be used to host the virtual machines and services I build throughout the project.

---

## Why I Built This Homelab

As I continue developing my IT skills, I wanted a way to practice real administrative tasks in an environment that I could fully control.

Instead of only learning about technologies such as Active Directory, Windows Server, networking, and cloud administration through coursework, this homelab gives me the opportunity to configure them myself, make mistakes, troubleshoot issues, and document what I learn throughout the process.

Because this is my first homelab, the project is also focused on building a strong foundation before moving into more advanced infrastructure and cloud topics.

---

## Project Goals

The main goals of this homelab are to gain practical experience with:

- Proxmox VE and virtualization
- Creating and managing virtual machines
- Windows Server administration
- Active Directory Domain Services
- DNS and DHCP
- Creating and managing users, groups, and computers
- Organizational Units and Group Policy
- Windows domain environments
- Linux administration
- Networking and IP configuration
- Remote system administration
- Backup and recovery
- Troubleshooting and documentation
- PowerShell and administrative automation
- Microsoft Azure
- Hybrid cloud and identity concepts
- General system administrator responsibilities

---

## Long-Term Goal

The long-term goal of this project is to build a small simulated business IT environment.

As the homelab expands, I plan to create an environment that includes:

- A Proxmox virtualization host
- Windows Server systems
- Active Directory
- Domain joined Windows clients
- Centralized user and group management
- Group Policy
- DNS and DHCP services
- Linux systems
- File and network services
- Monitoring and logging
- Microsoft Azure integration
- Hybrid cloud administration

The goal is not only to get these technologies working, but to understand how they are configured, how they interact with each other, and how to troubleshoot them when something goes wrong.
